# Movie-Store
A modular movie rental inventory system in C++ with a strong emphasis on polymorphism and the factory pattern to support dynamic behavior and easy extensibility. The system handles multiple genres (Comedy, Drama, Classics), each with unique sorting logic, and supports borrowing, returning, inventory listing, and transaction history for customers.

## How it Works:
Designed with polymorphism and the factory pattern, allowing easy extensibility (e.g., new genres or commands can be added without modifying existing logic). Implemented a custom hash table for fast customer lookup and maintained clean separation of concerns using over 10 well-documented classes. Developed robust error handling for invalid inputs and ensured the system could be compiled and run modularly, following best practices in scalable and maintainable software design.
